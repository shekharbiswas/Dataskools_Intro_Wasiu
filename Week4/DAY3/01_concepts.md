# 📘 Day 3 — Concepts: GitHub + Engineering Journal

## 🎯 Goal for Today
A short, reflective day. We organize our work from the past two days into a
clean repo, and write our first journal entry — a habit real data
engineers keep to track decisions and progress over time.

---

## 🧠 Core Terms (Day 3 Glossary)

| Term | Plain-English Meaning |
|---|---|
| **Repository (repo)** | A folder tracked by Git — holds our code, data, and docs together. |
| **Commit** | A saved checkpoint of our work, with a short message explaining what changed. |
| **Version control** | The practice of tracking changes over time so we can see history and undo mistakes. |
| **Engineering journal** | A running log of what we built, what broke, and what we learned — useful for ourselves and anyone reviewing our work later. |

---

## ❓ One Reflection Prompt
What's one thing from Day 1 or Day 2 that we'd do differently if we started
over? Keep this in mind — we'll write about it today.
